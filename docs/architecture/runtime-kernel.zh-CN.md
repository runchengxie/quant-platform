# 运行时内核契约

语言：简体中文 · [English](runtime-kernel.md)

`quant-platform` 维护确定性运行时，把研究目标转换为订单、成交、账本更新和不可变证据。运行时内部使用类型化事件控制流程。仓库之间只交换有版本的契约和不可变产物。

执行感知型运行必须在运行清单中记录数据版本、交易日历版本、策略和引擎版本、执行策略、成本模型及随机种子。市场数据视图会检查每条记录的生效时间是否不晚于知识截止时点。订单事件必须符合类型化生命周期，也不能让订单超量成交或修改终态订单。

交易前规则返回 `PASS`、`REJECT` 或 `ADJUST`。规则按稳定顺序执行，调整后的结果会传给下一条规则，拒绝则停止处理。运行时事件描述交易日内的生命周期，但不会构成跨仓库事件总线。不可变证据记录已发生的事情。未来如增加检查点功能，也应单独保存可变的恢复状态。
