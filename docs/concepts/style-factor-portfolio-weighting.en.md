# Retired style-factor backtest slice

Language: English · [简体中文](style-factor-portfolio-weighting.md)

This is a historical notice, not a usage guide. The quantile-portfolio backtest described by the former page was removed from the public `quant-platform` distribution. Function names and parameters in the old examples are not supported by the current `portfolio_backtester` API.

The migration slice was excluded from the public release on 2026-09-07 because the source code's license and historical authorization had not been confirmed. See [commit `62d4a25`](https://github.com/runchengxie/quant-platform/commit/62d4a254409cd3111fc90083a892308fa598c98c) and `config/migration/provenance.json`. The recorded private target has not been created. This repository does not ship the slice or claim a replacement API for it.

The previous technical text remains available in Git history for provenance. Use the current [public API reference](../reference/public-api.md) and implementation as the source of truth for supported interfaces.
