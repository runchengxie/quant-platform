# DailyWatch20 portfolio ownership

Language: English · [简体中文](ownership-migration.md)

`portfolio_backtester.daily_watch20_oos` is the authoritative implementation for DailyWatch20 portfolio construction, turnover, trading costs, and direction-related tradability diagnostics.

Signal generation and statistical promotion evidence remain in the upstream research repository. This repository accepts signals through stable input/output contracts and produces portfolio and backtest results.
