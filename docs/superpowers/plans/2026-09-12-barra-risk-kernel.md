# Plan: Barra-like risk model kernel

> **For the executor:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (or execute each task with the same isolation and test discipline) while implementing this plan.

**Goal:** Add a public, strategy-agnostic Barra-like risk-model kernel to `portfolio_backtester` that accepts point-in-time exposure/return panels, estimates daily factor returns and covariance, and reconciles portfolio volatility and factor contributions. A-share factor construction, data-provider adapters, and private strategy holdings remain outside this change.

**Design reference:** `quant-market-research/docs/superpowers/specs/2026-09-12-barra-risk-model-design.md` in the companion worktree/repository.

**Scope guard:** This is not a commercial Barra-compatible implementation. It must not import `quant-research`, vendor clients, credentials, raw market data, or strategy-specific names. Tests use deterministic synthetic data only.

## Task 1: Define the public risk-model contracts and validation behavior

**Files:**
- Create `packages/portfolio-backtester/src/portfolio_backtester/risk_model.py`.
- Create `tests/test_risk_model.py`.
- Modify `packages/portfolio-backtester/src/portfolio_backtester/__init__.py`.

**Implementation details:**

1. Add frozen dataclasses:

   ```python
   @dataclass(frozen=True)
   class RiskModelConfig:
       periods_per_year: float = 252.0
       min_cross_section: int = 3
       ridge: float = 1e-10
       covariance_window: int = 252
       ewma_halflife: float = 60.0
       covariance_shrinkage: float = 0.10

   @dataclass(frozen=True)
   class FactorReturnResult:
       factor_returns: pd.DataFrame
       residual_returns: pd.DataFrame
       diagnostics: pd.DataFrame

   @dataclass(frozen=True)
   class RiskModelResult:
       factor_returns: pd.DataFrame
       factor_covariance: pd.DataFrame
       specific_variance: pd.Series
       diagnostics: pd.DataFrame

   @dataclass(frozen=True)
   class PortfolioRiskAttribution:
       portfolio_exposure: pd.Series
       factor_contribution: pd.Series
       specific_variance: float
       total_variance: float
       total_volatility: float
   ```

2. Define canonical input conventions in docstrings. Exposures are a wide DataFrame indexed by `("as_of_date", "symbol")` with one numeric column per factor; asset returns are a Series or one-column DataFrame with the same MultiIndex and name `total_return`. Portfolio weights are a Series indexed by symbol for one model date. Do not silently accept duplicate keys.

3. Add `validate_risk_inputs(exposures, returns, *, config=None)` that checks index names, numeric values, finite returns, duplicate keys, and a positive cross-section. Raise `ValueError` with the offending field/date rather than dropping invalid rows. Missing factor exposures may be represented as `NaN` and are handled per date by the estimator; missing returns are rejected for the rows used in a regression.

4. Export the dataclasses and validation function from `portfolio_backtester.__init__` and include them in `__all__`.

5. Tests must cover valid canonical panels, duplicate `(date, symbol)` rejection, missing index names, non-finite returns, and a cross-section smaller than `min_cross_section`.

## Task 2: Implement daily weighted cross-sectional factor-return estimation

**Files:**
- Modify `packages/portfolio-backtester/src/portfolio_backtester/risk_model.py`.
- Modify `tests/test_risk_model.py`.

**Implementation details:**

1. Implement:

   ```python
   def estimate_factor_returns(
       exposures: pd.DataFrame,
       returns: pd.Series,
       *,
       weights: pd.Series | None = None,
       config: RiskModelConfig | None = None,
   ) -> FactorReturnResult:
   ```

2. For each date, align finite returns with rows whose factor exposure is present, add an intercept only when the caller supplies a factor named `intercept` (the kernel itself must not manufacture one), and solve weighted ridge least squares. Use square-root observation weights and `numpy.linalg.solve`/`lstsq`; do not add a statsmodels dependency.

3. Return `factor_returns` with index `as_of_date` and factor columns, `residual_returns` with the original `(as_of_date, symbol)` index and columns `total_return`, `fitted_return`, `residual_return`, and `diagnostics` with `n_observations`, `rank`, `condition_number`, `weighted_r2`, and `status`. Dates below `min_cross_section` get status `insufficient_cross_section` and are not estimated.

4. Add deterministic synthetic tests where returns are exactly generated by two factors plus residuals. Assert recovered coefficients within tolerance, residual reconstruction, weighted-vs-unweighted behavior, and a diagnostic for an underdetermined date.

## Task 3: Implement factor covariance, PSD stabilization, and specific risk

**Files:**
- Modify `packages/portfolio-backtester/src/portfolio_backtester/risk_model.py`.
- Modify `tests/test_risk_model.py`.

**Implementation details:**

1. Implement:

   ```python
   def build_risk_model(
       factor_returns: pd.DataFrame,
       residual_returns: pd.DataFrame,
       *,
       config: RiskModelConfig | None = None,
   ) -> RiskModelResult:
   ```

2. Estimate factor covariance from the trailing `covariance_window` rows using EWMA weights based on `ewma_halflife`. Apply diagonal shrinkage toward the average variance using `covariance_shrinkage`.

3. Symmetrize the covariance and project tiny negative eigenvalues to zero. Expose the stabilized covariance with factor labels preserved. Estimate specific variance per symbol from residual returns using the same trailing/EWMA convention; return nonnegative values and `NaN` only for symbols with no valid residual history.

4. Diagnostics must record sample count, effective sample size, shrinkage, minimum eigenvalue before/after stabilization, and per-symbol residual observations.

5. Tests must assert covariance symmetry, PSD within tolerance, factor-label preservation, nonnegative specific variance, and correct behavior for one-factor/short-history panels.

## Task 4: Implement portfolio risk exposure and factor attribution

**Files:**
- Modify `packages/portfolio-backtester/src/portfolio_backtester/risk_model.py`.
- Modify `tests/test_risk_model.py`.

**Implementation details:**

1. Implement:

   ```python
   def attribute_portfolio_risk(
       weights: pd.Series,
       exposures: pd.DataFrame,
       factor_covariance: pd.DataFrame,
       specific_variance: pd.Series,
   ) -> PortfolioRiskAttribution:
   ```

2. Align symbols strictly, calculate portfolio factor exposure `B.T @ w`, factor variance `b.T @ Sigma @ b`, specific variance `sum(w_i^2 * specific_variance_i)`, and total volatility as the square root of total variance. Reject missing portfolio symbols, negative specific variances, and covariance factors not present in exposures.

3. Define factor contribution as Euler contribution to variance `b * (Sigma @ b)` and ensure it sums to factor variance. The result object must expose a stable `Series` index for factor names.

4. Tests must verify exact synthetic attribution, factor contribution reconciliation, specific-plus-factor variance reconciliation, and validation errors for missing symbols/factors.
