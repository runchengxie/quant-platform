# 匹配模型和风险比较

这些研究辅助函数用于分离估计器比较和组合核算。它们不实现交易策略，也不负责证明点时数据来源有效。

## 按时间顺序拟合

`alpha_research.matched_rank_models.fit_matched_rank_models` 接受训练和推理 DataFrame、特征名、决策日期以及注册配置。训练键包括 `formation_date`、`symbol`、`label_end_date` 和 `target`。推理行需要 `formation_date`、`symbol` 以及相同的特征列。

所有训练建仓日期和标签成熟日期都必须严格早于决策日期。每一条推理记录都必须属于当前决策日期。

缺失特征使用训练列中位数填充，训练列全部缺失时使用 0。目标值必须为有限值。默认目标变换是在建仓日期内计算百分位排名，并对并列值取平均。`identity` 模式保留数值型风险目标。

支持的估计器包括 Ridge、标准化 Ridge、随机森林、逐点 XGBoost 和成对 XGBoost。成对模型要求目标为排名，并使用 `rank:pairwise` 目标函数，训练观测按建仓日期分组。

返回值包含预测结果和一份回执，其中记录填充中位数、解析后的配置、成熟度边界，以及实际训练行的哈希。匹配哈希可以支持相同输入比较，但不能证明源特征在历史上确实已经可用。

分数不代表经过校准的预期收益，也不代表概率。点时来源、样本外切分、冻结的实验规格、权重转换和执行成本评估由调用方负责。

## 风险目标和准入

`alpha_research.downside_target.next_close_downside_target` 在次日收盘入场后，使用指定数量的交易所交易日计算日度下行 RMS。正收益交易日仍计入分母。缺失价格或非正价格会生成不可用目标，不会延长计算区间，也不会默认填 0 收益。

`trailing_downside_rms` 提供对应的历史观测控制指标。

`alpha_research.forecast_skill_gate.forecast_skill_gate` 将此前生成的 OOF 模型预测和控制预测与实际目标比较。每个建仓期都必须严格早于决策日期并且已经成熟。固定启发式要求至少 8 个建仓期，每期至少 20 个匹配且有限的观测，建仓期平均 MSE 改善为正，获胜建仓期比例至少为 60%。

该方法不能证明调用方提供的预测确实来自折外数据。布尔输出不是置信概率，也不是显著性检验。

始终要把学习得到的风险权重与简单暴露控制进行比较。波动率较低本身不能证明预测能力，事后匹配波动率的比较属于回看诊断，不能直接作为可执行的配置规则。回撤深度、未恢复区间、恢复时间、换手率和净收益仍由组合层评估。
