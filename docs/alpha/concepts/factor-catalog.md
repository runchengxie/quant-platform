# 因子目录

因子目录把可复用因子登记为带版本的研究资产，避免只靠 Python 函数名识别因子。

每个 `FactorSpec` 记录：

- 稳定的因子标识和明确版本
- 负责人和频率
- 声明的依赖
- PIT 语义
- 形成股票池语义
- 预处理流程
- 实现代码的 SHA-256
- 可选说明

`FactorEvidenceSummary` 记录按日期保存的证据，不嵌入原始研究结果。首批字段包括 IC、秩 IC、ICIR、换手率、中性化秩 IC、衰减期限、观测数量和生命周期状态（`research`、`candidate`、`production`、`retired`）。

同一个因子可以有多个版本。证据必须关联到一个明确的 `(factor_id, version)`，同一因子版本在同一天出现重复证据时，目录会拒绝通过。

本设计参考 RQFactor 讨论的因子生命周期和产品化思路，同时把 PIT 语义和证据归属保留在本平台。以后可以接入 Alphalens Reloaded 做差异化报告检查，但它不承担标准因子身份目录的职责。
