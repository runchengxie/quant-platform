# Alpha namespace

Language: English · [简体中文](namespace-migration.md)

- Canonical Python package: `alpha_research.*`
- Canonical contract prefix: `alpha_research.*`
- The documented removal target for legacy compatibility entry points was workspace 2.0.

The current distribution installs `alpha_research`. The shared workspace 1.x namespace, compatibility facade, and aliases have since been removed. New code, documentation, and artifact contracts should use the owner-native names.
