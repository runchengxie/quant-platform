# 语言本地化规范

语言：简体中文 · [English](LANGUAGE_POLICY.md)

`quant-platform` 的公共工程接口和可复用文档以英文为规范版本。可以为
中文读者提供配套译文，但不得形成第二个独立事实源。

## 契约与产物

- Python 标识符、公共 API、CLI 参数、schema key、产物字段、错误码和机器
  可读元数据使用英文或与语言无关的命名。
- 生成的 JSON、CSV、Parquet 元数据和回执不得依赖某一种人类语言才能解释。
- 人类可读的渲染器可以在生成类型化模型或产物之后本地化标题、标签和说明。
- locale 与时区、货币、交易日历和数值精度相互独立。

## 文档

`README.md`、API 文档、规格说明、ADR 和契约定义以英文为规范版本。中文译文
使用 `.zh-CN.md` 后缀或明确成对的目录，并链接回英文规范文档。契约语义不得
在两份副本中独立编辑。

策略假设、专有特征和策略结论仍属于私有研究仓库。本仓库只记录可复用机制和
公开证据。

## 迁移规则

本地化既有文档时，保留代码块、标识符、文件路径、schema 示例和精确命令输出。
优先翻译正在使用的入口文档，注释和历史归档待规范版本与配套译文稳定后再处理。

支持的公共 locale 标识为 `en-US` 和 `zh-CN`。实现必须拒绝未知 locale，而不是
静默改变契约语义。
