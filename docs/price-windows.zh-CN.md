# 转换研究价格窗口

[English](price-windows.md)

使用 `quant_platform.prices.convert_price_window`，将截至指定时点可用的原始行情
转换为 RAW、供应商因子尺度的 HFQ 或 PIT QFQ。接口只转换研究输入。成交、股数、
费用、公司行为和现金记账仍由 Core 负责。

完整可运行示例见[英文文档](price-windows.md)。示例原价为 `[100, 50, 60]`，
因子为 `[1, 2, 2]`，最后一天 PIT QFQ 输出为 `[50, 50, 60]`。

## 输入和观察时间

行情与因子表都要求 `symbol`、`trade_date`、`available_at`。行情还需所选价格字段，
默认是 OHLC。因子表还需 `adj_factor`。RAW 只要求行情和 `source_ref`。复权模式
额外要求因子及 `factor_source_ref`。来源引用为调用方提供的非空标识，最好绑定
不可变清单或内容哈希。

`trade_date` 为不带时区的午夜日期。`as_of` 和所有 `available_at` 必须带时区，
统一为 UTC。行情日期上限取 `as_of` 的上海日期。仅日期或数值时间戳会被拒绝。
行情与因子分别按自己的观察时间选版本，恰好等于截止时刻的观察可用。同一证券、
行情日期允许多个已观察版本，先选当时最新版本再连接。相同证券、日期和观察时间
的重复行拒绝。未来行情日期与后来观察被排除。结果保留选中行的输入顺序和索引，
日期与时间字段统一格式。

接口只能验证声明的时钟，无法认证供应商实际何时发布数据。不能给最新重建历史
编造过去的可用时间。按交易日期截断最新因子表不能证明 PIT。历史可用性结论需要
真实观察版本及独立来源审计。

## 单位与缺失值

| 口径 | 历史 s 日公式 | 含义 |
| --- | --- | --- |
| `raw` | 原价 | 原始每股价格单位 |
| `hfq` | 原价 × F_s | 未归一化的供应商因子尺度 |
| `pit_qfq` | 原价 × (F_s / F_t) | 各证券截至行情日期上限的最新可用因子基准 |

HFQ 不保证历史首价保持不变。供应商因子方向和定义必须符合乘法契约。停牌期间，
PIT 基准可以晚于最后一条可用行情，但不会补出新行情。当前行情自身因子作为基准
时，转换价等于原价。

必要历史因子缺失或不可用、行情窗口为空、无效因子、已观察价格非正数或非有限值、
转换后非空价格无效均抛出 `ValueError`。不把因子默认为 1，不前填价格。空价格
保持为空。因子必须有限且为正。PIT 先计算因子比再乘原价，避免不必要的中间溢出。
额外行情列，包括成交量和成交额，原样复制。已知非价格字段不能作为转换目标。

`PriceWindow` 包含 `prices`、`basis`、UTC `as_of`、来源引用和 `anchors`。
PIT 基准表包含 `symbol`、`trade_date`、`adj_factor`、`available_at`。RAW/HFQ
返回相同列结构的空基准表。输入不会被修改。包装对象字段冻结，但独立 DataFrame
仍可修改，因此它不是不可变产物或执行请求。与 pandas 深拷贝一致，额外列里的嵌套 Python 对象仍共享引用，要求源对象隔离时不能通过结果修改这些嵌套对象。

## 研究与账户使用

相同因子与缺失值处理下，HFQ、QFQ 的尺度不变动量和均线比较一致。齐次的价格型
指标可以按相同基准换尺度。非线性指标不能一概除以因子。

原始股数账户使用原价撮合和估值，另行处理审计后的公司行为，不在复权收益上
重复叠加分红送股。复权总收益和原价账户只有在再投资、税、结算时点、成交价及
成本假设匹配时才可能相等。延迟到账或现金留存都可能造成合理差异。本接口不认证
事件完整性、可交易性、账户权益、历史费用或原价停牌估值能力。
